# Traffic Rush 3D

Three.js + TypeScript ашигласан, browser дээр тоглодог 3D траффик уралдааны тоглоом (Traffic Racer маягийн).

## Ажиллуулах

```bash
npm install
npm run dev
```

Дараа нь browser-оо `http://localhost:5173` хаягаар нээнэ.

Production build хийх (гарсан `dist/` хавтсыг ямар ч static host — Netlify, Vercel, GitHub Pages дээр байршуулж болно):

```bash
npm run build
npm run preview
```

## Удирдлага

| Товч | Үйлдэл |
| --- | --- |
| `←` `→` / `A` `D` | Жолоодох |

| `↓` / `S` | Тоормослох |

| `H` | Дохио (horn) |

Утас, таблет дээр дэлгэцэн дээрх товчлуурууд автоматаар гарч ирнэ.

## Тоглоомын онцлог

- **2 горим**: Нэг чиглэлт, Хоёр чиглэлт (эсрэг урсгалын эгнээнд явбал оноо ×2)
- **Өдөр / Шөнө**: шөнө гудамжны гэрэл, машины гэрэл, барилгын цонх асна
- **Оноо**: туулсан зай + 120 км/ц-ээс дээш хурдтай бол ×1.5
- **Ойрхон өнгөрөх (near miss)**: машины хажуугаар ойрхон өнгөрвөл бонус оноо, дараалсан бол КОМБО
- **Нитро**: ойрхон өнгөрөх бүрт цэнэглэгдэнэ
- **Траффик AI**: машинууд урдах машинаа дагаж хурдаа тохируулна, эргэлтийн гэрэл асаагаад эгнээ солино
- **9 төрлийн машин**: седан, хэтчбэк, жийп, фургон, такси, цагдаа (гялалздаг гэрэлтэй), спорт, ачааны машин, автобус
- Хүндрэл зай нэмэгдэх тусам өснө (илүү олон машин, хурдан траффик, олон эгнээ солилт)
- Шилдэг оноо горим бүрээр browser-т хадгалагдана
- Бүх дуу WebAudio-оор синтезлэгдсэн (хөдөлгүүр, нитро, мөргөлдөөн, дохио) — нэмэлт файл хэрэггүй

## Бүтэц

```
src/
  main.ts      — эхлэх цэг
  game.ts      — тоглоомын төлөв, оноо, камер, үндсэн цикл
  world.ts     — зам, тэнгэр, мод, барилга, гэрэлтүүлэг, өдөр/шөнө
  cars.ts      — машины 3D загварууд (процедураар үүсгэсэн)
  traffic.ts   — траффикийн AI, гарч ирэх, мөргөлдөөн шалгах
  player.ts    — тоглогчийн машины физик
  input.ts     — гар, мэдрэгчтэй удирдлага
  audio.ts     — WebAudio дуу
  effects.ts   — оч (spark) эффект
  ui.ts        — HUD, цэс
  config.ts    — тохиргооны тогтмолууд
```

Тоглоомын тохиргоог (хурд, хурдатгал, эгнээний өргөн гэх мэт) `src/config.ts` дотроос өөрчилж болно.
